# «عُمان تُروى من جديد»: لعبة تعليمية ثلاثية الأبعاد

لعبة تعليمية تفاعلية باللغة العربية تعمل في المتصفح على الكمبيوتر والموبايل.

- تتحكم الطالبة بشخصية **«مريم»** بزيّها العُماني.
- تبدأ الرحلة من **بوابة عُمان**، ثم **الساحة التراثية**، وفي وسطها خريطة عُمان المجسّمة.
- حول الساحة **خمس محطات**: حمد بن سيف (الملاحة)، سمهرم، السلاحف، العاج (التجارة)، الملابس العُمانية.
- في كل محطة: معلومات، ونشاط تفاعلي، وتحدٍّ بأسئلة «صح أو خطأ»، وختم في **«جواز مستكشف عُمان»**.
- محطة إضافية: **قلعة نزوى** مع ساحة تحدٍّ وشهادة إتمام، و**لوحة معلم** لتعديل الأسئلة.

النماذج مبنية بالكامل في **Blender 5.2** عبر سكربتات Python، والعرض بتقنية **React Three Fiber** (three.js).

- **العب الآن:** https://khaildalhadil.github.io/oman-door/
- **الفيديو التوضيحي:** في صفحة [Releases](https://github.com/khaildalhadil/oman-door/releases).
- **وصف توظيف اللعبة في المنهج:** `docs/وصف-توظيف-اللعبة-في-المنهج.docx`

كل دفع (push) إلى الفرع `main` يبني اللعبة وينشرها تلقائياً على GitHub Pages عبر `.github/workflows/deploy.yml`.

## التشغيل

```bash
cd web
npm install
npm run dev
```

ثم افتح الرابط: http://localhost:5173

- للنشر: `npm run build` يُنتج المجلد `web/dist`، ويمكن رفعه على أي استضافة مواقع ثابتة.
- يمكن فتح اللعبة من الموبايل على نفس الشبكة بالأمر `npm run dev -- --host`.

| الجهاز | الحركة | الجري | القفز | التفاعل | الكاميرا |

## المحطات

| المحطة | النشاط | ختم الجواز |
|---|---|---|
| حمد بن سيف: الملاحة | «اهتدِ بالنجوم»: إيجاد نجم الجاه (القطبي) في السماء الشمالية | بعد المعلومات + النشاط + التحدي |
| سمهرم | «عالِم الآثار الصغير»: الحفر في ٥ تلال لاكتشاف قطع أثرية | بعد المعلومات + النشاط + التحدي |
| السلاحف | «رحلة الصغار إلى البحر»: إطفاء المصابيح ثم إرشاد الصغار | بعد المعلومات + النشاط + التحدي |
| العاج: التجارة | «طريق السلع»: مطابقة السلع مع موانئها على خريطة المحيط الهندي | بعد المعلومات + النشاط + التحدي |
| الملابس العُمانية | «ما اسم هذه القطعة؟» و«خزانة مريم» لتغيير ألوان زيّها | بعد المعلومات + النشاط + التحدي |

بعد الأختام الخمسة يظهر وسام «مستكشف عُمان». ويمكن تحميل الجواز صورةً من نافذة الجواز.

## تعديل المحتوى

- **نصوص المحطات وأسئلتها:** في `web/src/stations.ts`.
  - سيرة «حمد بن سيف» (`bio`) نص مؤقت، ويجب استبداله بنص مقالة الموسوعة.
- **نصوص البوابة وقلعة نزوى:** في `web/src/content.ts`.
- **أسئلة تحدي قلعة نزوى:** تُعدَّل من داخل اللعبة عبر زر «المعلم» (الرمز `1234`، ويُغيَّر في `web/src/ui/Teacher.tsx`).
  - التعديلات تُحفظ في المتصفح.
  - زرّا «تصدير» و«استيراد» ينقلان بنك الأسئلة بين الأجهزة.
- **الفيديو داخل مجلس القلعة:** ضع ملف mp4 في `web/public/video/`، وغيّر `VIDEO.src` في `content.ts`.

تقدّم الطالبة (الاسم والأختام واللون المختار) يُحفظ في `localStorage` على جهازها. وزر «رحلة جديدة» في الجواز يمسح الأختام.

## ملفات بلندر

كل مشهد له سكربت في `blender/`، ويُصدِّر:

- `web/public/models/<name>.glb`
- `<name>_colliders.json` (التصادم ونقطة البداية)
- `blender/blend/<name>.blend` (الأنسجة مدمجة، وغير موجود في المستودع لكبر حجمه، ويُعاد توليده بالسكربت)
- صورة معاينة في `blender/renders/`

| السكربت | المشهد |
|---|---|
| `build_girl.py` | الشخصية «مريم» (ووجهها المرسوم `textures/face_open.png`) وصورة `web/public/images/maryam.png` |
| `build_gate.py` | بوابة عُمان |
| `build_plaza.py` | الساحة التراثية وخريطة عُمان والمداخل الخمسة |
| `build_stations.py` | المحطات الخمس (`nav`, `sumhuram`, `turtles`, `ivory`, `clothing`) |
| `build_fort.py`, `build_interior.py`, `build_quiz.py` | قلعة نزوى، ومجلسها، وساحة التحدي |
| `build_palm.py` | النخلة (تُكرَّر بتقنية instancing) |

```bash
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --factory-startup -P blender/build_all.py
```

```bash
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --factory-startup -P blender/build_stations.py -- turtles ivory
```

- الأمر الأول يعيد توليد كل شيء. أضف `-- --textures` لإعادة توليد الأنسجة، و`--video` للفيديو المؤقت.
- الأمر الثاني مثال على إعادة بناء محطات محددة.

تحويل الإحداثيات: إحداثيات بلندر (x, y, z) تصبح في three.js (x, z, −y).

## الهيكل

```
blender/            سكربتات بناء النماذج (lib.py, textures.py, scenery.py, props.py, build_*.py)
web/src/three/      المشاهد (Gate, Plaza, Station, Fort, Interior, QuizCourt) والشخصية والأنشطة
web/src/ui/         الواجهة (المقدمة، الجواز، المحطات، الأسئلة، لوحة المعلم، التحكم)
web/src/game/       الإدخال، والتصادم، والأصوات، والبوصلة، وبنك أسئلة نزوى
web/src/stations.ts محتوى المحطات الخمس
web/src/store.ts    حالة اللعبة والرحلة
docs/               الفيديو التوضيحي ووصف توظيف اللعبة في المنهج
```

## ملاحظة عن المعلومات

النماذج تمثيل فني مستوحى من المعالم الحقيقية، وليست نسخاً هندسية دقيقة منها. معلومات المحطات مختصرة من مصادر موثوقة، ويُفضَّل مطابقتها مع مقالات الموسوعة المعتمدة في المدرسة.
