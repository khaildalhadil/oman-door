# «عُمان تُروى من جديد»: لعبة تعليمية ثلاثية الأبعاد

لعبة تعليمية تفاعلية باللغة العربية تعمل في المتصفح على الكمبيوتر والموبايل.

- تتحكم الطالبة بشخصية **«مريم»** بزيّها العُماني.
- تبدأ الرحلة من **بوابة عُمان**، ثم **الساحة التراثية**، وفي وسطها خريطة عُمان المجسّمة.
- حول الساحة **خمس محطات** مبنية على مواد الموسوعة العُمانية: حمد بن سيف البوسعيدي، سمهرم، السلاحف البحرية، تجارة العاج، الملابس العُمانية.
- في كل محطة: لغز «من أنا؟»، ومعلومات، ونشاط تفاعلي، و«تحدي المستكشف»، وبطاقة «اكتشفي معلومة» مع المرجع، ثم ختم في **«جواز مستكشف عُمان»**.
- محطة إضافية: **قلعة نزوى** مع ساحة تحدٍّ وشهادة إتمام، و**لوحة معلم** لتعديل الأسئلة.

النماذج مبنية بالكامل في **Blender 5.2** عبر سكربتات Python، والعرض بتقنية **React Three Fiber** (three.js).

- **العب الآن:** https://khaildalhadil.github.io/oman-sea-story/
- **الفيديو التوضيحي:** في صفحة [Releases](https://github.com/khaildalhadil/oman-sea-story/releases).
- **وصف توظيف اللعبة في المنهج:** `docs/وصف-توظيف-اللعبة-في-المنهج.docx`

كل دفع (push) إلى الفرع `main` يبني اللعبة وينشرها تلقائياً على GitHub Pages عبر `.github/workflows/deploy.yml`.

## التشغيل

```bash
cd web
npm install
npm run dev
```

ثم افتح الرابط: http://localhost:5173

- للنشر: `npm run build` يُنتج المجلد `web/dist`، ويمكن رفعه على أي استضافة مواقع ثابتة.
- يمكن فتح اللعبة من الموبايل على نفس الشبكة بالأمر `npm run dev -- --host`.

## المحطات

محتوى المحطات من **الموسوعة العُمانية**، وكل محطة تتبع القالب نفسه:

**اكتشفي (لغز «من أنا؟») ← بطاقات المحتوى (النقاط المضيئة) ← النشاط ← تحدي المستكشف ← «اكتشفي معلومة» 💡 ← المرجع 📚 ← ختم في الجواز**

| المحطة (مادة الموسوعة) | اللغز | النشاط | تحدي المستكشف |
|---|---|---|---|
| حمد بن سيف البوسعيدي (قاضٍ ومؤرخ) — مجلس العلم | «فمن أنا؟» | جمع ٤ مخطوطات مضيئة في المجلس | ترتيب محطات حياته من الأقدم إلى الأحدث |
| سمهرم / خور روري | «فأين أنا؟» | الحفر في ٥ تلال لاكتشاف قطع أثرية | «اختاري مفتاح المدينة» 🔑 |
| السلاحف البحرية في عُمان | «فمن أنا؟» | إطفاء المصابيح وإرشاد الصغار إلى البحر | مطابقة كل سلحفاة بصفتها |
| تجارة العاج (عُمان وشرق إفريقيا) | «فما أنا؟» | «اختاري طريق التاجر» على الخريطة | اختيار عوامل ازدهار تجارة العاج |
| الملابس العُمانية | — | «ما اسم هذه القطعة؟» و«خزانة مريم» | ٣ أسئلة صح أو خطأ |

- محطة الملابس بانتظار مادة الموسوعة «الدشداشة النسائية العُمانية»، وستُحوَّل إلى القالب نفسه عند وصولها.
- بعد الأختام الخمسة يظهر وسام «مستكشف عُمان». ويمكن تحميل الجواز صورةً من نافذة الجواز.

## استوديو التحديات (للطالبات)

**الرابط:** https://khaildalhadil.github.io/oman-sea-story/studio.html (ويوجد رابط له أيضاً في «لوحة المعلم»).

صفحة بسيطة بلا برمجة، تصمّم فيها الطالبات محطة كاملة:

- لغز «من أنا؟» (الوصف، والسؤال، والخيارات، والإجابة الصحيحة).
- بطاقات المحتوى: المعلومة، والمرجع (المجلد والصفحة)، والتسجيل الصوتي بالميكروفون أو برفع ملف.
- التحديات: اختيار من متعدد، أو ترتيب، أو مطابقة، أو عدة إجابات، أو صح وخطأ، مع رسالة الإجابة الصحيحة.
- الختام: بطاقة «اكتشفي معلومة»، والمرجع العام، وكلمة الختام بالصوت.

طريقة العمل:

1. يُحفظ العمل تلقائياً على الجهاز (IndexedDB).
2. زر «جرّبي» يعرض كل تحدٍّ بنوافذ اللعبة نفسها، وزر «جرّبي المحطة كاملة» يعرض اللغز ثم التحديات ثم الختم.
3. زر «جرّبيها في اللعبة» يطبّق التصميم على اللعبة **في هذا الجهاز فقط**، ويفتح المحطة مباشرة (`?preview=<id>`).
4. زر «تنزيل الملف» يُنتج ملف `.json` (فيه الأصوات) يُرسل إلى المعلمة، ويُفتح من جديد بزر «فتح ملف تصميم».
5. **النشر للجميع:** ضع الملف في `web/public/content/<id>.json` (مثل `nav.json`)، وأضف اسم المحطة في `web/public/content/manifest.json`، ثم ادفع إلى `main`.

نقاط المشهد ثابتة (لكل محطة ٤–٥ نقاط مضيئة)، والتصميم يغيّر نصوصها وأصواتها. والبطاقة الفارغة تُخفي نقطتها.

## تعديل المحتوى

- **نصوص المحطات وألغازها وتحدياتها ومراجعها:** في `web/src/stations.ts` (حقول `riddle` و`items` و`challenge` و`fact` و`ref`).
  - أنواع التحدي المتاحة: `order` (ترتيب)، `match` (مطابقة)، `choice` (اختيار واحد)، `multi` (اختيار عدة إجابات)، `tf` (صح أو خطأ).
- **نصوص البوابة وقلعة نزوى:** في `web/src/content.ts`.
- **أسئلة تحدي قلعة نزوى:** تُعدَّل من داخل اللعبة عبر زر «المعلم» (الرمز `1234`، ويُغيَّر في `web/src/ui/Teacher.tsx`).
  - التعديلات تُحفظ في المتصفح.
  - زرّا «تصدير» و«استيراد» ينقلان بنك الأسئلة بين الأجهزة.
- **الفيديو داخل مجلس القلعة:** ضع ملف mp4 في `web/public/video/`، وغيّر `VIDEO.src` في `content.ts`.

تقدّم الطالبة (الاسم والأختام واللون المختار) يُحفظ في `localStorage` على جهازها. وزر «رحلة جديدة» في الجواز يمسح الأختام.

## ملفات بلندر

كل مشهد له سكربت في `blender/`، ويُصدِّر:

- `web/public/models/<name>.glb`
- `<name>_colliders.json` (التصادم ونقطة البداية)
- `blender/blend/<name>.blend` (الأنسجة مدمجة، وغير موجود في المستودع لكبر حجمه، ويُعاد توليده بالسكربت)
- صورة معاينة في `blender/renders/`

| السكربت | المشهد |
|---|---|
| `build_girl.py` | الشخصية «مريم» (ووجهها المرسوم `textures/face_open.png`) وصورة `web/public/images/maryam.png` |
| `build_gate.py` | بوابة عُمان |
| `build_plaza.py` | الساحة التراثية وخريطة عُمان والمداخل الخمسة |
| `build_stations.py` | المحطات الخمس (`nav`, `sumhuram`, `turtles`, `ivory`, `clothing`) |
| `build_fort.py`, `build_interior.py`, `build_quiz.py` | قلعة نزوى، ومجلسها، وساحة التحدي |
| `build_palm.py` | النخلة (تُكرَّر بتقنية instancing) |

```bash
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --factory-startup -P blender/build_all.py
```

```bash
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --factory-startup -P blender/build_stations.py -- turtles ivory
```

- الأمر الأول يعيد توليد كل شيء. أضف `-- --textures` لإعادة توليد الأنسجة، و`--video` للفيديو المؤقت.
- الأمر الثاني مثال على إعادة بناء محطات محددة.

تحويل الإحداثيات: إحداثيات بلندر (x, y, z) تصبح في three.js (x, z, −y).

## الهيكل

```

web/src/three/      المشاهد (Gate, Plaza, Station, Fort, Interior, QuizCourt) والشخصية والأنشطة
web/src/ui/         الواجهة (المقدمة، الجواز، المحطات، الأسئلة، لوحة المعلم، التحكم)

web/src/store.ts    حالة اللعبة والرحلة
docs/               الفيديو التوضيحي ووصف توظيف اللعبة في المنهج
```

النماذج تمثيل فني مستوحى من المعالم الحقيقية، وليست نسخاً هندسية دقيقة منها. نصوص المحطات من الموسوعة العُمانية، والمرجع مذكور في نهاية كل محطة.
