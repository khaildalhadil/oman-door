# تصاميم الطالبات المنشورة

ضع هنا ملف التصميم الذي صدّرته الطالبات من «استوديو التحديات» باسم المحطة:

- `nav.json` (حمد بن سيف)
- `sumhuram.json`
- `turtles.json`
- `ivory.json`
- `clothing.json`

ثم أضف اسم المحطة إلى `manifest.json`، مثل `["nav"]`، وادفع إلى `main` فيظهر التصميم في اللعبة للجميع.
